# 💻 Windows 12 Simulator (`win12_sim.py`)

**XS TEAM** tarafından geliştirilen, modern ve minimalist konsept tasarımlardan esinlenilmiş 2D **Windows 12 İşletim Sistemi Simülatörü**!

Bu proje, Python ve **Pygame** kullanılarak geliştirilmiştir. Yüzen dock tasarımı, pencere yönetimi, web tarayıcısı, müzik çalar ve özelleştirilebilir masaüstü temaları gibi etkileşimli özellikler içerir.

---

## ✨ Özellikler

- 🌊 **Yüzen Görev Çubuğu (Windows 12 Dock):** Ekranın altında havada duran modern ve yuvarlatılmış görev çubuğu.
- 🪟 **Sürüklenebilir Pencere Sistemi:** Uygulamaları başlık çubuğundan tutup ekranda serbestçe taşıyabilme ve kapatabilme (`X`).
- 🌐 **Edge 12 Web Tarayıcısı:** Arama çubuğu üzerinden arama yapma ve dinamik sonuç simülasyonu.
- 🎵 **XS Sound Müzik Çalar:**
  - Canlı ses spektrum (dalga) animasyonu.
  - `SPACE` tuşu ile oynatma / duraklatma kontrolü.
- 🖼️ **Kişiselleştirme & Tema Değiştirici:** Tek tıkla canlı masaüstü duvar kağıdı ve vurgu rengi değiştirme.
- 📁 **Dosya Gezgini & Başlat Menüsü:** Sistem bilgilerini ve dosya dizinini görüntüleyen özel menüler.
- ⏰ **Canlı Sistem Saati:** Sağ üst köşede anlık saat takibi.

---

## 🛠️ Kurulum ve Çalıştırma

Projeyi bilgisayarınızda çalıştırmak için Python 3.x ve `pygame` kütüphanesinin kurulu olması gerekmektedir.

### 1. Kütüphaneyi Yükleyin
Terminal veya Komut Satırına (CMD) şu komutu yazın:

pip install pygame

### 2. Simülatörü Başlatın
Proje klasöründe terminali açıp şu komutla simülatörü çalıştırın:

python win12_sim.py
